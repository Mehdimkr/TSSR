# 🖥️ Histoire des systèmes d'exploitation (OS)

## 1. Les besoins d'un ordinateur

- **CPU** (*Central Processing Unit*) : le processeur, exécute les instructions.
- **RAM** (*Random Access Memory*) : mémoire vive, rapide et temporaire.
- **MB** (*Motherboard*) : la carte mère, relie tous les composants.

L'**OS** (*Operating System*) fait le lien entre le matériel et les applications.

## 2. Les débuts

- **1945** : **ENIAC** (*Electronic Numerical Integrator And Computer*), premier ordinateur électronique généraliste, sans OS.
- **1968** : création d'**Intel**.
- **1971** : Intel 4004, premier microprocesseur.
- **1975** : **Altair 8800**, l'un des premiers micro-ordinateurs.
- **1978** : **Intel 8086**, architecture **CISC** (*Complex Instruction Set Computing*), base de la famille x86. À l'opposé, **RISC** (*Reduced Instruction Set Computing*) : peu d'instructions simples (ex. ARM).

## 3. Unix et ses descendants

- **1970 : Unix**, « père des OS », **multitâche** et multi-utilisateur. Le **1er janvier 1970** est l'*Epoch* : le point de départ du comptage du temps sous Unix.
- **Années 80 : BSD** (*Berkeley Software Distribution*), dérivé d'Unix. Variantes libres :
  - **FreeBSD** : usage général, performance.
  - **OpenBSD** : sécurité.
  - **NetBSD** : portabilité.
- **2001 : Mac OS X** (puis macOS), basé sur Unix/BSD (via NeXTSTEP et Darwin).
- **1991 : Linux**, noyau libre inspiré d'Unix, créé par Linus Torvalds.
- **2007 : Android**, basé sur Linux (annonce en 2007, premier téléphone en 2008).

## 4. Windows

- **1985** : Windows 1.0.
- **1993** : **Windows NT** (*New Technology*), stable, pour les entreprises.
- **2000** : Windows 2000 (NT 5.0).

```text

```
